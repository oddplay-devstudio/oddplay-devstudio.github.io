삭제를 요청하는 방법

이메일 한 통이면 됩니다.

  1. oddplay.devstudio@gmail.com으로 제목에 [슉슉] 데이터 삭제 요청이라고 적어 보내주세요.
  2. 본문에 기기 모델과 앱을 설치·사용한 대략의 시기를 적어주세요. 슉슉은 계정이 없어 이 정보로만 사용자를 찾습니다.
  3. 접수 후 14일 이내에 처리 결과를 같은 이메일로 회신합니다.

삭제되는 데이터와 보관되는 데이터

슉슉은 사진·얼굴 정보를 서버로 보내지 않습니다. 기기 밖으로 나가는 것은 앱 사용 통계와 오류 기록뿐입니다.

데이터어디에 있나삭제 요청 시요청이 없어도
등록한 얼굴 정보·매크로 설정 사용자 기기 안에만 저장 서버에 사본이 없어 저희가 삭제할 대상이 없습니다. 앱을 삭제하거나 Android 설정 → 앱 → 슉슉 → 저장공간 → 데이터 삭제를 하면 즉시 지워집니다.
공유하려고 앱에 넘긴 사진 처리 중 기기 안 임시 저장소 해당 없음(기기 밖으로 나가지 않음) 처리 후 자동 삭제됩니다.
앱 사용 통계
(Firebase Analytics — 화면·기능 사용 이벤트, 기기 종류, 광고 ID·앱 인스턴스 ID)		 Google Firebase 서버 요청자가 알려준 정보로 식별 가능한 범위에서 삭제합니다. 계정이 없어 특정이 불가능한 경우 그 사실을 회신합니다. 수집일로부터 최대 14개월 뒤 자동 삭제됩니다.
오류·비정상 종료 기록
(Firebase Crashlytics)		 Google Firebase 서버 위와 같습니다. 90일 뒤 자동 삭제됩니다.

법령에 따라 보관해야 하는 데이터는 없습니다. 슉슉은 계정·이름·이메일·연락처를 수집하지 않습니다.

직접 할 수 있는 것

  • 광고 ID 재설정·삭제: Android 설정 → 개인정보 보호(또는 Google) → 광고 → "광고 ID 삭제". 이후 수집되는 통계는 이전 기록과 연결되지 않습니다.
  • 앱 데이터 전부 삭제: 앱 삭제, 또는 설정 → 앱 → 슉슉 → 저장공간 → 데이터 삭제.
